Wander install errors and fixes

Common errors the Wander Installer or your iPhone can show while you install Wander, in the order you meet them. Find your error, read what it means, then follow the numbered steps.

Checked 17 Nov 2026 with Wander Installer 2.3.3 on macOS and an iPhone on iOS 26.6.1 (Windows steps from the install guide)

New to the install? Start with the install guide on the download page. Come back here when something goes wrong.

Tip: press Ctrl+F (or Command+F on a Mac) and paste part of your error message. Each error below is written out word for word so you can find it.

macOS: Wander Installer "can't be opened", "not trustworthy" or "damaged"

When you first open the Installer, macOS may say one of these things:

  • Wander Installer can't be opened
  • Wander Installer is not trustworthy
  • Wander Installer is damaged

What it means: the Installer is not signed with a paid Apple developer account, so macOS blocks it.

If you downloaded the Installer from wanderspoofer.com/download, the message comes from the missing paid signature, not real damage. If you got it anywhere else, delete it and download it again from the official page.

On current macOS, right-click then Open no longer gets past this. Use one of the two fixes below. If the message says damaged, use Fix A.

Fix A: Terminal

  1. Drag Wander Installer into your Applications folder.
  2. Open Terminal. It is in Applications > Utilities.
  3. Paste this command and press Return: 
    xattr -cr /Applications/Wander\ Installer.app
  4. Open Wander Installer again.

Fix B: System Settings

  1. Try to open Wander Installer once. When macOS blocks it, click Done.
  2. Open System Settings > Privacy & Security.
  3. Scroll down to the Security section.
  4. Click Open Anyway next to the Wander Installer message.
  5. Confirm with your Mac password or Touch ID.
  6. Click Open Anyway again.

Windows: the PC can't see the iPhone

What it means: Windows needs Apple's device software before it can talk to an iPhone over USB.

  1. Install Apple Devices from the Microsoft Store. Or install iTunes from apple.com.
  2. Plug in the iPhone and unlock it.
  3. Open the Wander Installer. If SmartScreen (the Windows download filter) warns you, click More info, then Run anyway.

"Failed to select device": missing PairRecordData

Failed to select device
Failed to get pairing record for device: unexpected response from device: missing PairRecordData

What it means: the iPhone has not trusted this computer yet. A pairing record is the saved "I trust this computer" link between the two.

Your iPhone must have a passcode set for this to work.

  1. Unlock the iPhone and stay on the home screen.
  2. Unplug the cable and plug it back in.
  3. When the iPhone asks "Trust This Computer?", tap Trust.
  4. Enter your iPhone passcode.
  5. Try again in the Installer.

No "Trust This Computer?" prompt? (Mac)

  1. Keep the iPhone plugged in and unlocked.
  2. Open Finder.
  3. Click your iPhone in the Finder sidebar.
  4. Click Trust. Then answer the prompt on the iPhone.

Last resort: reset the trust settings

This resets location and privacy settings for every app. Apps will ask again for location, camera, photos and other access. Your iPhone will also stop trusting every computer it trusted before. Source: Apple Support.
  1. On the iPhone, open Settings > General > Transfer or Reset iPhone > Reset.
  2. Tap Reset Location & Privacy.
  3. Plug the iPhone back in, unlock it, and tap Trust when asked.

"Login failed": error sending request for url (gsa.apple.com)

Login failed
error sending request for url (https://gsa.apple.com/grandslam/GsService2/lookup)

Under More Details you may also see:

tcp connect error ... Operation timed out

What it means: your computer could not reach Apple's sign-in server for a moment. Nothing was sent to Apple yet, so nothing is lost.

  1. Click Login again.
  2. If it happens again, check for a VPN, firewall or network filter on the computer. One of these may be blocking the connection to Apple.

Sign-in seems stuck on "Logging in..."

Logging in...

What it means: Apple's server can be slow.

  1. Wait up to a minute.
  2. Do not click Login again while you wait.

Why not? Every click starts a separate sign-in, and the attempts compete. Each new attempt also asks Apple for a new verification code. That cancels the codes from earlier attempts. So a code you type in may no longer work (see Auth error -27589).

The Apple verification code never arrives

Apple Account Sign-In Requested

When your Apple Account signs in on a computer for the first time, Apple asks for a two-factor verification code. Two-factor means Apple wants your password plus a 6-digit code.

Apple normally shows an "Apple Account Sign-In Requested" pop-up on your trusted devices. A trusted device is an iPhone, iPad or Mac already signed in to your Apple Account. Tap Allow to see the 6-digit code.

What it means if nothing appears: sometimes the pop-up never shows up. You can still get a code from your iPhone yourself.

On iOS 18 and iOS 26, the Get Verification Code button in Settings is hidden while the iPhone is online. It comes back when the iPhone is offline.

  1. On your trusted iPhone, turn on Airplane Mode. Make sure Wi-Fi is off too.
  2. Open Settings and tap your name at the top.
  3. Tap Sign-In & Security.
  4. A pop-up titled "Account Details Unavailable" appears. Tap Get Verification Code in it.
  5. Type the 6 digits into the Installer's code box right away.
  6. Turn Airplane Mode off.

Apple also lets you get a code by text or phone call to your trusted phone number. Look for "Didn't Get a Code?" on the sign-in screen. The Wander Installer does not offer a text-message option unless Apple requests one, so use the offline method above.

The full walkthrough is in our post Apple verification code not showing up? Sources: Elcomsoft, 19 Jun 2026 and Apple Support.

"Login failed": Auth error -27589

Login failed
Auth error -27589

What it means: this appears right after you submit a code. Apple rejected the code. Apple does not document this number.

The likely cause is a code from an earlier sign-in attempt. This happens if Login was clicked more than once (see Stuck on "Logging in..."). We are not certain this is the only cause.

  1. Close the error.
  2. Click Login once.
  3. Wait for the code box to appear.
  4. Get a fresh code: tap Allow on the pop-up, or use the offline method.
  5. Enter the code right away.

"Place Pairing File" fails: device socket io failed

Failed to get installed apps: device socket io failed

What it means: the USB connection dropped for a moment during the "Place Pairing File" step. The Wander app itself has already been installed by then.

  1. Keep the iPhone unlocked.
  2. Unplug the cable and plug it back in. Use a port directly on the computer, not a hub.
  3. Click Install Wander again. This re-runs all the steps.
  4. If it keeps happening, try another cable.

"Maximum number of installed apps" error

maximum number of installed apps

What it means: a free Apple ID can have at most 3 sideloaded apps on one device at a time. Sideloaded means installed from a computer instead of the App Store. The Installer says: "You can only have 3 sideloaded apps installed at a time with a free Apple ID."

Expired sideloaded apps still count toward the limit of 3.

  1. On the iPhone, delete a sideloaded app you no longer use.
  2. Click Install Wander again.

"Application verification failed": 0xe8008024 or 0xe8008018

0xe8008024
0xe8008018 (The identity used to sign the executable is no longer valid.)

The text after 0xe8008024 says the provisioning profile is blocked. A provisioning profile is the file that lets an app signed with your Apple ID run on your iPhone.

What it means: The reports point to Apple blocking some Apple IDs from installing apps they sign. The Installer signs Wander with your Apple ID. Then the iPhone refuses the app at the install step.

People using other sideloading tools report it too. The reports do not show what triggers it. In the test linked below, a new certificate, key and app identifier did not get past it. Checked 17 Nov 2026.

0xe8008018 can also mean an expired or revoked signing certificate. Try the install once more first.

  1. Click Install Wander again.
  2. Same error? Then Apple is most likely blocking that Apple ID. The reported workaround is to sign in with a different Apple ID that belongs to you.

Sources: two reports on GitHub for iloader, an open-source sideloading installer. In issue 583, its developer says the error does not appear to be limited to iloader. In issue 653, a tester's blocked Apple ID still failed with a new certificate, key and app identifier, and a second Apple ID installed on the same iPhone.

Installing for a friend or family member: use their own Apple ID

Use the phone owner's own Apple ID, not yours. They need to be there to sign in and approve the code.

Why: Wander renews with whichever Apple ID installed it, once you sign in to that Apple ID in Wander's Settings. So install with the Apple ID of the person who uses the phone.

  1. Have the phone's owner sign in to the Installer with their own Apple ID.
  2. Have them approve the verification code on their own devices.

iPhone says "Untrusted Developer"

Untrusted Developer

What it means: the iPhone does not yet trust apps signed with your Apple ID.

  1. Open Settings > General > VPN & Device Management.
  2. Under Developer App, tap your Apple ID email.
  3. Tap Trust.
  4. Tap Trust again to confirm.

Developer Mode is missing or off

What it means: Wander needs Developer Mode turned on. The setting usually appears once a developer-signed app such as Wander is installed.

  1. Open Settings > Privacy & Security.
  2. Scroll to the bottom of the list and tap Developer Mode.
  3. Turn it on, then tap Restart.
  4. After the restart, unlock the iPhone and tap Turn On (some iOS versions say Enable).
  5. Enter your passcode.

No Developer Mode row? Open Wander once, then check again. More detail: iPhone Developer Mode not showing.

Wander expires after 7 days

What it means: apps signed with a free Apple ID expire after 7 days.

  1. In Wander, open Settings and sign in to your Apple ID. Wander can then renew itself.
  2. If Apple asks, enter a verification code (see above).

Wander stores the password on that phone so it can renew. Background: why sideloaded iPhone apps expire after 7 days.

Wander reports "Connection reset" (code 54)

Connection reset

The error shows code 54.

LocalDevVPN is a free App Store app. Wander uses it as its connection to the iPhone's own developer services.

What it means: LocalDevVPN's tunnel address is the same address Wander connects to. The phone ends up connecting to itself, and the connection is reset.

  1. Open LocalDevVPN and go to its settings.
  2. Set Tunnel IP to 10.7.1.1.
  3. Set Device IP to 10.7.1.0.
  4. Reconnect LocalDevVPN.
  5. Leave Wander's own tunnel IP settings at their defaults.

Using cellular data with no Wi-Fi

What it means: on cellular data with no Wi-Fi, LocalDevVPN needs one extra step after it connects.

  1. Connect LocalDevVPN.
  2. Turn Airplane Mode on.
  3. Turn Airplane Mode off again.

FAQ

What does "missing PairRecordData" mean?

It means the iPhone has not trusted this computer yet. Unlock the iPhone, unplug it and plug it back in, then tap Trust on the "Trust This Computer?" prompt and enter your passcode.

Why does macOS say Wander Installer is damaged or can't be opened?

The app is not signed with a paid Apple developer account, so macOS blocks it. If you downloaded it from wanderspoofer.com/download, the message comes from the missing signature, not real damage. Run xattr -cr /Applications/Wander\ Installer.app in Terminal, or click Open Anyway in System Settings > Privacy & Security. If the message says damaged, use the Terminal command.

Why is my Apple verification code not showing up?

Sometimes the sign-in pop-up never reaches your trusted devices. On iOS 18 and iOS 26 you can still make a code yourself: turn on Airplane Mode with Wi-Fi off, open Settings > [your name] > Sign-In & Security, and tap Get Verification Code in the pop-up.

What does "Auth error -27589" mean?

Apple rejected the verification code. Apple does not document this number. The likely cause is a code from an earlier sign-in attempt. Click Login once, wait for the code box, and enter a fresh code right away.

How do I fix "Untrusted Developer" on iPhone?

Open Settings > General > VPN & Device Management. Tap the Apple ID email under Developer App. Tap Trust, then tap Trust again.

Why is Developer Mode missing from Settings?

The Developer Mode row usually appears once a developer-signed app such as Wander is installed. Open Wander once, then check Settings > Privacy & Security again. The row is at the bottom of the list.
