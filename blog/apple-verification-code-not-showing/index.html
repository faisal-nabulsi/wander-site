Apple Verification Code Not Showing Up? How to Get One on iOS 18 and iOS 26

If the sign-in pop-up never reaches your iPhone, you can make a code yourself. On iOS 18 and iOS 26, turn on Airplane Mode and make sure Wi-Fi is off. Then open Settings, tap your name, then Sign-In & Security. Tap Get Verification Code in the pop-up that appears.

How Apple sends a verification code

Apple Accounts (formerly called Apple IDs) use two-factor authentication. That means signing in takes two things: your password and a 6-digit verification code.

Apple asks for the code when you sign in on a new device or browser. You may also be asked when an app on your computer signs in with your Apple Account. Sideloading tools that sign in with your Apple Account are one example. Sideloading means installing an app from a computer instead of the App Store.

Normally the code comes to you. Apple sends a sign-in notification to your trusted devices. A trusted device is an iPhone, iPad or Mac that is already signed in to your account. You tap Allow, and the code appears. Then you type it into the screen that asked for it.

The notification may include a map. Apple says the map is based on the new device's IP address, so it can show the wrong town. If you know the sign-in is yours, you can still tap Allow.

Why the code may not show up

Sometimes the sign-in pop-up never appears on your trusted devices. When that happens, many people go looking for the manual button. On iOS 17 it lived at Settings > [your name] > Sign-In & Security > Get Verification Code. On iOS 16 and earlier, that menu was called Password & Security.

On iOS 18 and iOS 26 that button seems to be gone.

Elcomsoft, a company that makes iPhone forensics tools, looked into this in June 2026. They note that many forum posts say Apple removed the button. They found it still exists. It now appears only when the iPhone itself is offline. While the phone is online, iOS hides it from Sign-In & Security.

Elcomsoft's explanation is that an online iPhone gets the code pushed to it automatically, so Apple dropped the manual button there. On iOS 17 and earlier, the button still shows whether the phone is online or not.

Get a code offline, step by step

Do this on a trusted iPhone, while the sign-in screen on your other device is waiting for a code.

  1. Turn on Airplane Mode.
  2. Check that Wi-Fi is off too. The iPhone needs to have no connection at all.
  3. Open Settings and tap your name at the top.
  4. Tap Sign-In & Security.
  5. A pop-up titled "Account Details Unavailable" appears. This is expected. It is not an error.
  6. Tap Get Verification Code in the pop-up. A 6-digit code appears.
  7. Type the code into the waiting sign-in screen right away.
  8. Turn Airplane Mode off again.
These steps match Elcomsoft's June 2026 write-up. Apple may move the button again in a later update.

Get a code by text or phone call

Apple also offers a code by text message or phone call. It goes to your trusted phone number, the number you added to your Apple Account for sign-in codes.

  1. On the verification code screen, select "Didn't Get a Code?" or "Can't get to your devices?".
  2. Choose to have the code sent to your trusted phone number.
  3. Wait for the text or call from Apple.
  4. Enter the code to finish signing in.

This only works where the sign-in screen offers that link. Not every app that signs in with your Apple Account shows it. If yours does not, use the offline method above.

If you filter Unknown Senders in Messages, check that list for the code. Apple says you can also let time-sensitive messages through. Go to Settings > Apps > Messages. Under Unknown Senders, tap Allow Notifications. Then turn on notifications for Time Sensitive messages.

Using a sign-in tool? Press Login once

This part is about tools that sign in to Apple for you, such as the Wander Installer. It is what we saw with the Wander Installer. It is not a documented Apple rule.

When a sign-in is slow, it is tempting to click Login again. Try not to.

In the Wander Installer, each click on Login starts a separate sign-in attempt. Each new attempt can ask Apple for a new code. A code from an earlier attempt may then be rejected, even if you type it correctly.

So start one sign-in. Wait up to a minute for the code box. Then get a fresh code and enter it right away.

If a code was rejected, close the error first. Then start one new sign-in and use a code from that attempt.

If you can't reach any trusted device or number

Apple says the fastest fix is to wait until you have your trusted device or phone number again, if that will be within a few days. Then sign in as normal. You can also add more trusted phone numbers for next time.

If you have lost access for good, Apple offers account recovery. Start a sign-in, select "Didn't Get a Code?", then choose "Can't use [phone number]". Apple says recovery can take a few days or longer, and contacting Apple can't speed it up.
